# Свои слои для карты

Карта при открытии читает список `layers/layers.json` и подгружает перечисленные в нём файлы GeoJSON.

## Как добавить слой

1. Сохраните слой в GeoJSON в системе координат WGS 84 (EPSG:4326).
   В QGIS: правый клик по слою → «Экспортировать» → «Сохранить объекты как…» → формат GeoJSON, СК EPSG:4326.
2. Положите файл в эту папку `layers/` репозитория (Add file → Upload files).
3. Добавьте строку в `layers/layers.json`:

```json
[
  {"file": "layers/primer_parkovki.geojson", "name": "Пример: парковки", "color": "#1e88e5"},
  {"file": "layers/moy_sloy.geojson", "name": "Мой слой", "color": "#d81b60"}
]
```

- `file` — путь от корня сайта; `name` — подпись в панели «Свои слои»; `color` — цвет (необязательно).
- Точки рисуются кружками, линии и полигоны — контуром с заливкой 25 %. По клику показываются первые 12 атрибутов.
- После коммита GitHub Pages обновляет сайт за 1–2 минуты.

## Ограничения

- Один файл до ~25 МБ (лимит веб-загрузки GitHub — 25 МБ, жёсткий лимит репозитория — 100 МБ на файл). Крупные слои упростите (QGIS: Векторный анализ → Упростить) и округлите координаты до 5 знаков.
- Локальная загрузка («Добавить GeoJSON с компьютера») работает и без GitHub, но слой виден только в вашем браузере до перезагрузки страницы.
- Пример `primer_parkovki.geojson` можно удалить вместе с его строкой в `layers.json`.
