# Карта: застройка в лесу и на угодьях (Выборгский и Приозерский районы)

`index.html` — самодостаточная карта (данные встроены). `layers/` — дополнительные слои GeoJSON, см. `layers/README.md`.
Публикация: Settings → Pages → Deploy from a branch → main / (root).
Топокарта OpenTopoMap и подгрузка слоёв из `layers/` работают только при открытии через сайт (https), а не из файла.
